# 가시제거연구소 데일리 브리핑 — 원격 루틴 작업 지시서

## 실행 명령

```bash
python main.py
```

이것이 유일한 실행 명령이다. 그 외 작업(웹 검색, 큐레이션, 요약 생성, 추가 분석)은 절대 금지.

## AI API 호출 금지

- LLM 요약, 번역, 재작성 등 AI API 호출 완전 금지
- 노션 API(`api.notion.com`)는 단순 페이지 생성용으로만 허용
- RSS 원본 텍스트를 그대로 사용할 것 (description 앞 110자 자동 절단만 허용)

## 섹션별 2단계 폴백 로직

### 1순위 (기본)
- 섹션 내 모든 RSS의 최근 24시간 내(KST 기준) 신규 항목 합산
- 발행시각 내림차순 정렬
- 시장뉴스: 최대 3건 / 블로그·유튜브: 최대 5건

### 2순위 폴백 (1순위 결과 0건일 때만 발동)
- 시장뉴스: 전체 RSS에서 발행시각 내림차순 최근 3건 (기간 제한 없음)
- 블로그·유튜브: 각 소스별 최신 1건씩 합쳐서 최대 5건 (기간 제한 없음)
- 발행시각 누락 항목 제외

### 섹션 라벨 형식
- 1순위 성공: `1. 시장 핵심 뉴스 🆕 24시간 내 신규 N건`
- 폴백 발동: `1. 시장 핵심 뉴스 📚 24h 신규 없음 — 최근 N건 참고`

## 에러 처리

- RSS 1개 실패해도 다른 소스 계속 진행 (에러 무시)
- 빈 페이지 생성 절대 금지

## 콘솔 출력 필수

실행 시 다음을 반드시 출력:
1. 시작 시간 (KST)
2. 소스별 수집 건수 (✓ 성공 / ✗ 실패)
3. 폴백 발동 여부
4. 생성된 노션 페이지 URL

## 환경변수

```
NOTION_API_KEY=...
NOTION_PARENT_PAGE_ID=...
```

코드에서 `os.environ.get("NOTION_API_KEY")` 형태로만 읽음.
실제 값은 `.env` 파일 또는 클라우드 환경변수에 등록.
`.env`는 `.gitignore`에 포함됨.
